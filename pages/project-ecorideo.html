EcoRideo

E-commerce storefront and admin interfaces for a bicycle and scooter shop.

My role

Independent page and product-card design, responsive layouts, and frontend implementation.

Tools

Tailwind CSS, Alpine.js, Flowbite, HTML and JavaScript.

Project environment

ASP.NET MVC with Razor views.

Brief & My Role

EcoRideo brings product browsing, product details, cart interactions and account screens into one shopping interface. An administration area provides views for products, orders, blog content, reviews and users.

I designed the pages and product cards independently and implemented the responsive frontend.

Full page — scroll to explore

Responsive Layout

I used Tailwind CSS utility classes for responsive layouts and shared visual styling. Alpine.js handles local interface state such as menus, panels, dialogs and form interactions. Flowbite provides UI components used within the project.

The implementation includes desktop and mobile layout rules, navigation controls and dark-mode styling.

Page Design & Benefit Cards

I designed the page sections and card layouts myself. The benefits section combines clear headings, icons, and a teal accent to organise information about delivery, support, and shopping.

Product Cards & Storefront

  • Homepage with a cycling hero image, product categories and shopping calls to action.
  • Product catalogue with filter controls and a mobile filter panel.
  • Product detail screens with image gallery, content tabs and review interactions.
  • Cart interface with quantity controls and price calculations.
  • Wishlist and account interfaces, including orders and profile information.

The product-card screen uses sample product content to demonstrate the interface layout.

Mobile Account Access

The mobile login screen groups email and password fields, password recovery, registration, and a Google sign-in option within one form.

Blog & Comments

The blog screen includes a comments panel over the article listing. Existing comments and a response form are grouped in the panel while the page remains visible behind it.

Administration interfaces

The administration area extends the project beyond a storefront. It includes product and order views, search and form controls, status presentation, and interfaces for managing content, reviews and users. These screens demonstrate table layouts and more detailed form interactions.

Current implementation

The project is in development. Some interactions use demonstration data or browser storage. In the reviewed catalogue logic, category and colour filtering are implemented; the other visible filter controls still require completion and testing.

This case study presents my design and frontend work. Checkout, payment processing, and server-side workflows are still in development.

What this project demonstrates

Building interfaces across a connected shopping journey, organising responsive components with Tailwind CSS, adding stateful interactions with Alpine.js, and working with storefront and administration screens in the same application.
