Outdoor Pictogram Set

A coordinated set of four outdoor activity pictograms.

Brief

An academic icon design project exploring how four outdoor activities can be represented as a coordinated set of pictograms.

Sketches / Design

Black silhouettes, a shared circular frame, and a consistent green palette connect the icons. The pose and objects in each illustration distinguish the individual activity.

Tools & Technologies

Adobe Illustrator

Final Result

A four-icon set with a recognizable shared style and a distinct silhouette for each activity.
